# My Algorithm Notes

这是我的算法笔记文档站。

我的成绩算不上亮眼：蓝桥杯 C/C++ A 组国二，Codeforces Rating 也只有 1500，放在算法竞赛领域，我显然称不上权威。

不过，我没有信奥的基础，也没有像许多 ACMer 那样长期、系统的训练。在这样的条件下，所取的成绩也足以让我满足了。在有限的学习和参赛经历中，我也逐渐积累了一些自己的理解与心得。它们未必深入全面，却足以帮助我解决大部分常见问题。

我想，对大多数人而言，也未必需要追逐复杂的算法或艰深的技巧。在此我试着梳理那些足以应对常见问题的基础知识与典型思路，一方面记录自己的理解，另一方面也希望能给偶然来到这里的人提供一点帮助。

这些内容大多来自我的整理与总结，难免会受到个人理解和能力的限制。如果发现错漏，欢迎通过 Issue 指正。
